## Projetos recentes

### 🎬 [Streaming Platform](https://github.com/lucas-mcarvalho/Streaming_Platform)

Plataforma de streaming full-stack para upload, organização e reprodução de filmes e séries pelo navegador. Catálogo responsivo com carrosséis, cadastro de usuários com autenticação JWT/OAuth2, gerenciamento de categorias, upload de vídeos e capas, e episódios múltiplos para séries.

- **Backend:** Java 21, Spring Boot, Spring Security, Spring Data JPA, Flyway
- **Frontend:** React 19, Vite
- **Banco de dados:** PostgreSQL
- **Infra & docs:** Docker, Docker Compose, Swagger/OpenAPI

### 📚 [TimerBook](https://github.com/lucas-mcarvalho/TimerBook_PS)

Plataforma para organizar livros, acompanhar metas de leitura e transformar o progresso do usuário em estatísticas claras. Inclui biblioteca digital de PDFs, leitor integrado com controle de progresso, metas diárias e streaks, sistema de conquistas e um assistente de IA durante a leitura. Em produção em [timerbook.com.br](https://timerbook.com.br).

- **Backend:** Java, Spring Boot, PostgreSQL
- **Frontend:** React
- **Serviços:** serviço de IA, landing page
- **Infra:** Docker, Docker Compose, AWS
